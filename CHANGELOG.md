# Change Log

All notable changes to the "Just a Midnight" theme will be documented in this file.

## [0.0.1] - 2025-01-12

### Initial Release
- Pure pitch black theme with #000000 backgrounds
- Borderless design with subtle separators
- Dark+ inspired syntax highlighting
- Custom theme configuration support via `.just-a-midnight-theme.json`
- Commands for creating and reloading custom configurations
- Optimized for late night coding sessions
